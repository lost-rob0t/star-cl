#+title: Readme

* Star-cl
Common Lisp bindings and compatibility runtime for StarIntel 0.10.1.

Star-Lang library =org.starintel/core@1= is the schema authority.  This
repository consumes its generated Common Lisp binding, JSON Schema,
compatibility policy, and shared migration fixtures at the exact commit pinned
in =schema/starintel-schema.lock.json=.

Canonical 0.10.1 document keys are lowerCamelCase.  snake_case is accepted only
by the legacy migration boundary.  Invalid legacy documents are quarantined and
the rest of the batch continues.

The =starintel/v0101= ASDF system and =starintel-v0101= package provide canonical
validation, round trips, migration, and capabilities.  The historical 0.9
runtime remains available explicitly through =starintel-v090.asd= and
=bin/starintel-conformance-v090.lisp=.


** Install
Install quicklisp
Git clone into the common-lisp directory
#+Name: install
#+begin_src sh :async :results output replace
git clone --recurse-submodules https://git.starintel.actor/nsaspy/star-cl.git ~/common-lisp/star-cl
#+end_src
